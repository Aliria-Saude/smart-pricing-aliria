    📋 Passo a passo

    1. Execute este SQL no Supabase → SQL Editor → New query:

    CREATE TABLE IF NOT EXISTS cmed ( id BIGSERIAL PRIMARY KEY, ean1 TEXT, ean2 TEXT, ean3 TEXT, produto TEXT, substancia TEXT, laboratorio TEXT, apresentacao TEXT ); CREATE INDEX IF NOT EXISTS idx_cmed_ean1 ON cmed(ean1); CREATE INDEX IF NOT EXISTS idx_cmed_ean2 ON cmed(ean2); CREATE INDEX IF NOT EXISTS idx_cmed_ean3 ON cmed(ean3); ALTER TABLE cmed ENABLE ROW LEVEL SECURITY; DO $$ BEGIN IF NOT EXISTS (SELECT 1 FROM pg_policies WHERE tablename='cmed' AND policyname='allow_all_cmed') THEN CREATE POLICY allow_all_cmed ON cmed FOR ALL USING (true) WITH CHECK (true); END IF; END $$;

    2. Baixe o arquivo CMED mais recente em gov.br/anvisa/cmed

    3. Arraste o arquivo nesta tela — o upload ocorre em lotes automaticamente (~25 mil registros)
